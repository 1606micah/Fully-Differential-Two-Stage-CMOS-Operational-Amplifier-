01 / Architecture

A complete signal path, not a black-box macro-model.

The design combines a high-gain fully differential front end, active common-mode regulation, and second-stage output drive. The original LTspice implementation is presented directly as design evidence.

01

Folded-cascode input

A fully differential PMOS input pair drives a high-output-resistance folded-cascode first stage for strong intrinsic gain at low branch current.

02

Common-source output

Complementary second-stage paths provide the additional voltage gain and differential output drive required for the 1 pF output loads.

03

Continuous-time CMFB

A dedicated common-mode sensing and error path regulates the average of OUTP and OUTN without disturbing the differential signal.

04

Lead-compensated Miller network

Dual 0.26 pF Miller capacitors and 1.5 kΩ nulling resistors establish the dominant-pole response and introduce useful phase lead.

02 / Results

Stability verified at the loop—not inferred from bandwidth.

Separate measurements answer separate engineering questions: open-loop response establishes gain and speed, return ratio establishes stability, and closed-loop response establishes usable signal bandwidth.

Application-loop margin

With the 100 kΩ / 100 kΩ feedback network, crossover shifts to 86.8 MHz while phase margin increases to 73.4°.

Closed-loop bandwidth

The differential closed-loop response remains flat near 0 dB through the passband and reaches −3 dB at 118.46 MHz.

Interpretation64.3° minimum differential-loop phase margin across the tested feedback configurations

The β = 1 test is the demanding stability case because it produces the highest differential-loop crossover frequency. The β = 0.5 application network provides additional phase margin.

03 / Verification

A test strategy built around failure modes.

The verification sequence moves from bias integrity to frequency response, loop stability, and nonlinear transient behavior—making each result traceable to a specific design risk.

DC

Operating point

Inspected internal node voltages, branch currents, output common mode, and device operating regions before frequency-domain characterization.

AC

Open- and closed-loop response

Measured nominal DC gain, unity-gain frequency, closed-loop gain, and −3 dB bandwidth using differential stimulus and response expressions.

LG

Return-ratio stability

Inserted series AC test sources at the differential and common-mode feedback junctions while preserving the DC operating point.

TRAN

Small- and large-signal steps

Checked bounded overshoot, settling behavior, output symmetry, and common-mode movement for both small and 1 V differential output transitions.

Engineering judgment

Results presented with their modeling boundary.

These are nominal schematic-level LTspice results using generic Level-1 MOS models. The models do not include realistic transistor parasitic capacitances, so the reported high-frequency figures demonstrate the compensated architecture—not fabricated-silicon performance.

The next verification layer would replace the generic models with a process design kit and add PVT corners, Monte Carlo mismatch, noise, PSRR, CMRR, distortion, output swing, and load-sweep characterization.
