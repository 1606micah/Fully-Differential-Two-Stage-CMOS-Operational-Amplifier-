# Fully Differential Two-Stage CMOS Op-Amp Portfolio

A static GitHub Pages portfolio for a personal analog IC design and verification project.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload every file and folder from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the **main** branch and **/(root)** folder, then save.
6. Add the resulting public URL to your resume project entry.

## Customize before publishing

- Replace the project label or add your name in `index.html`.
- Add your GitHub repository link beside the download button if desired.
- Keep the modeling-boundary section. It makes the project technically credible.
- Replace plot files in `assets/` only if you rerun the matching test.

## Included evidence

- Original LTspice schematic
- Unity-feedback and application-loop stability plots
- Differential closed-loop bandwidth plot
- Small- and large-signal transient plots
- Downloadable LTspice `.asc` source

No build tools are required. The site is plain HTML, CSS, and JavaScript.
